# 📊 Power BI Projects

Welcome to my **Power BI Projects** repository! This repository showcases interactive business intelligence dashboards built using **Microsoft Power BI**, **Power Query**, **DAX (Data Analysis Expressions)**, and **Data Modeling**. Each project demonstrates my ability to transform raw datasets into meaningful insights through dynamic visualizations, KPIs, maps, and interactive reports.

These dashboards are designed to solve real-world business and analytical problems while following modern dashboard design principles.

# 📁 Projects Included

## 🗳️ 1. 2024 Lok Sabha Election Analysis

An interactive Power BI dashboard that analyzes the **2024 Indian General Election** using official election data. The report provides detailed insights into election results at the national, state, and constituency levels.

### Key Features

* Interactive Home Page with report navigation
* Advanced DAX calculations
* NDA, INDIA Alliance & Other Seats KPIs
* Winning Alliance Analysis
* Winning, Runner-up & Second Runner-up Candidate Analysis
* Vote Share (%) & Winning Margin
* Party-wise Seat Distribution
* State-wise Geographic Maps
* State Analysis with Dynamic Slicers
* Constituency-Level Analysis
* Complete Election Results Grid

**Skills Demonstrated**

* Advanced DAX
* Power Query
* Data Modeling
* Geographic Analysis
* KPI Design
* Interactive Dashboard Development
* Election Data Analysis
